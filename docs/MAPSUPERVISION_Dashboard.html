🤖 Phương Án Tối Ưu AI Local (Qwen On-Device)

1

Chọn Inference Engine

Dùng MediaPipe LLM Inference API (Google) — hỗ trợ Qwen2, stable, có GPU/NPU acceleration. Dependency: tasks-genai:0.10.22

2

Model Size & Quantization

Qwen2-1.5B INT4 quantized (~800MB). Kiểm tra RAM trước khi load: thiết bị <4GB RAM → hiện thông báo "Không hỗ trợ AI" thay vì crash OOM.

3

Prompt Templates chuẩn hóa

Object InspectionPrompts với Qwen chat template (<|im_start|>). Cover: anomaly detection, report summary, photo classification.

4

Streaming Response + StateFlow

Dùng generateResponseAsync callback → emit từng token → Compose recompose smooth với AiState.Generating(partialText).

5

Lifecycle Management

Close inference engine khi app background >5 phút. Re-initialize on resume. Tránh memory leak từ native model handle.

6

DeviceCapability Check

Enum: OPTIMAL / CPU_ONLY_SLOW / INSUFFICIENT_RAM. Detect Qualcomm Hexagon, MediaTek APU cho GPU acceleration.
