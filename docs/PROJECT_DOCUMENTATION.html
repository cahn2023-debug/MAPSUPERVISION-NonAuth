1. Tổng quan dự án

MapSupervision là một ứng dụng Android đa module phục vụ quản lý và giám sát công trình hạ tầng. Hệ thống kết hợp GIS, ảnh hiện trường, nhập dữ liệu từ tệp, nhật ký tiến độ, xuất báo cáo và một subsystem AI/chat để hỗ trợ thao tác nhanh trong bối cảnh dự án.

Dựa trên file settings.gradle.kts, root project include các module: :app, :core, :domain, :data, :project, :gis, :gis-maplibre, :photo, :timeline, :reporting, :storage-core, :storage-crypto, :storage-import.

Root build.gradle.kts còn có kiểm tra ràng buộc phụ thuộc giữa module, giúp giữ cấu trúc theo hướng sạch: domain không phụ thuộc ngược lên data, storage, hay app; các module UI dựa vào domain và một số module hạ tầng cần thiết.

3. Kiến trúc và phụ thuộc

Cấu trúc tổng thể đi theo hướng presentation → domain → data/storage. Các màn hình và view model ở layer UI gọi use case/repository interface trong domain, rồi domain được hiện thực bởi data hoặc các module storage tương ứng. 

app
├─ project / gis / photo / timeline / reporting
├─ data / storage-core / storage-crypto / storage-import
└─ domain
   └─ core

Từ build.gradle.kts, project còn enforce dependency boundaries ở cấp module. Điều này giúp giữ repo ổn định khi số lượng màn hình và subsystem tăng lên.

Nhóm phụ thuộc Ý nghĩa
UI modules Phụ thuộc vào domain và một số module hạ tầng để dựng màn hình, view model và pipeline.
Data Hiện thực repository interface của domain, quản lý Room, network, ML/AI helper.
Storage Chia tách xử lý file, crypto và import để dễ bảo trì và kiểm thử.
Core Không phụ thuộc ngược, đóng vai trò nền tảng dùng chung.

4. Dữ liệu và database

Layer dữ liệu xoay quanh MapSupervisionDatabase, một Room database version 19 chứa các entity cho dự án, tiến độ, ảnh, nhật ký, nhập file, AI cache, chat history và report draft.

Các DAO chính gồm ProjectDao, GisNodeDao, GisRouteDao, SitePhotoDao, DailyLogDao, TaskDao, NoteDao, MaterialProgressDao, WorkCategoryDao, AiDecisionCacheDao, ChatHistoryDao, ReportDraftDao.

Những model domain trọng tâm gồm: Project, GisNode, GisRoute, NodeProgress, MaterialProgress, SitePhoto, DailyLog, Note, Task, ImportedFile, ChatHistoryMessage, ReportDraft, WorkspaceSnapshot.

Điểm đáng chú ý: Project có thêm metadata version, storage mode và đường dẫn DB riêng, cho thấy project đã tiến hoá từ mô hình lưu trữ chung sang mô hình per-project rõ ràng hơn.

5. AI và chat flow

Subsystem AI của repo không chỉ là một lớp gọi model, mà là một pipeline điều phối theo tài nguyên thiết bị, loại nhiệm vụ và trạng thái hệ thống.

Thành phần Trách nhiệm
app/.../AIManager.kt Phân loại prompt đơn giản hay phức tạp. Nếu đơn giản hoặc thiết bị thiếu tài nguyên, xử lý ngay bằng parser rule-based. Nếu phức tạp và tài nguyên đủ, đẩy sang HeavyAIWorker qua WorkManager.
domain/.../ChatActionParser.kt Chuyển prompt hoặc response từ LLM thành kết quả hành động có cấu trúc.
domain/.../ChatDictionaryResolver.kt Chuẩn hóa từ khóa và hỗ trợ nhận diện lệnh nhanh theo dictionary/normalization.
domain/.../AiOrchestrator.kt Smart router cho các capability AI. Chọn engine theo thiết bị, tài nguyên, feature flag và cache.

Các engine được nhìn thấy trong domain gồm: RuleBasedEngine, CloudGeminiEngine, LocalLiteRtEngine, MediaPipeLlmEngine, MlKitVisionEngine, TfliteVisionEngine.

1. Prompt vào

Người dùng nhập lệnh vào UI chat/workspace.

Đây là luồng thực tế được suy ra từ code trong AIManager.kt và AiOrchestrator.kt.

6. Storage, import và bảo mật

Hệ thống lưu trữ được chia tách theo dự án. ProjectStorageManager tạo cây thư mục riêng cho từng project trong Downloads/MapSupervision/Projects/<slug>, rồi đảm bảo các thư mục con cần thiết đã tồn tại.

Thành phần Vai trò
ProjectStorageManager Quản lý thư mục dự án, tạo photos/Nodes, thumbs, reports, exports, imports, db.
ProjectCryptoManager Mã hóa/giải mã bằng AES/GCM trên Android Keystore, có hàm diagnostics để kiểm tra key có hardware-backed hay không.
UserFileImportService Nhập và preview file, hỗ trợ KML/KMZ, GeoJSON/JSON và Excel, đồng thời đọc thêm một số tài liệu phụ trợ.

UserFileImportService cho thấy dự án có một pipeline import khá thực dụng: copy tệp vào thư mục import, parse summary, sinh draft gợi ý node/route, và phân biệt giữa file non-Excel với file Excel.

Trong photo, PhotoPipelineService tạo file chụp, thêm watermark/stamp, tạo thumbnail và có hàm OCR để trích xuất dữ liệu vật tư hoặc nhật ký từ ảnh.

7. GIS, photo và reporting

GIS

Module :gis và :gis-maplibre chịu trách nhiệm hiển thị bản đồ, nodes/routes, chọn phần tử và đo khoảng cách. MapBridgeInstaller khởi tạo MapLibre và gắn bridge render vào registry dùng chung của GIS UI.

Các symbol đáng chú ý: GisViewModel, GisScreen, MapLibreGisMapBridge, MapRenderKey, GisMapBridgeRegistry.

Photo

Module :photo tập trung vào chụp ảnh hiện trường và xử lý hậu kỳ. Dữ liệu ảnh gắn với GPS, timestamp, object code và các trường stamp khác. PhotoPipelineService tạo ảnh đầu ra, thumbnail, và hỗ trợ import từ gallery.

Reporting

Module :reporting gom dữ liệu từ node progress, material progress, site photo và daily log để dựng nội dung báo cáo. ReportExportBuilder chuẩn hóa content đầu ra, còn PdfReportGenerator và các màn hình reporting xử lý xuất file và preview.

Kết luận ngắn

Repo này là một ứng dụng Android khá hoàn chỉnh cho giám sát dự án hạ tầng, với ranh giới module rõ, dữ liệu Room có tiến hóa, GIS là một trục trung tâm, và AI/chat được tích hợp theo hướng thực dụng: rule-based trước, heavy AI sau, có cache và fallback.

Nếu cần, mình có thể làm tiếp một bản HTML thứ hai theo kiểu “sơ đồ kiến trúc kỹ thuật” hoặc “tài liệu cho người mới vào dự án” với mức chi tiết còn sâu hơn ở từng module.

Tài liệu này được tổng hợp từ cấu trúc module và các symbol hiện có trong codebase MapSupervision.
